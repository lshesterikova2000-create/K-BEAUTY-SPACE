# K-Beauty Space — готовий статичний сайт

## Запуск
1. Розпакуйте ZIP-архів.
2. Відкрийте `index.html` у браузері для локального перегляду.
3. Для публікації створіть GitHub-репозиторій і завантажте всі файли та папку проєкту.
4. У репозиторії відкрийте **Settings → Pages**.
5. У розділі Build and deployment виберіть **Deploy from a branch**, гілку `main` та папку `/ (root)`, натисніть Save.
6. Після публікації GitHub покаже адресу сайту.

## Функції
- адаптивна головна сторінка українською;
- каталог із 18 демонстраційними позиціями, пошук, категорії та сортування;
- кошик із підрахунком суми та кількості;
- демонстраційна форма оформлення замовлення з вибором способу оплати;
- контактна інформація, Instagram і TikTok;
- демонстраційна локальна адмінпанель (`admin.html`).

## Важливі обмеження
Це статичний frontend-проєкт, придатний для GitHub Pages. GitHub Pages не виконує серверний код і не надає базу даних. Тому:
- форма замовлення демонстраційна та не надсилає замовлення магазину;
- оплата карткою та IBAN не підключена;
- післяплата не передає дані до Нової пошти;
- адмінпанель не захищена серверною авторизацією, а її зміни локальні для браузера;
- реальні облікові записи, синхронізація залишків, клієнти, відгуки, бонуси й повідомлення потребують backend та інтеграцій.

Перед комерційним запуском підключіть сервер, базу даних, безпечну адмін-авторизацію, платіжного провайдера, API Нової пошти, політику конфіденційності й юридичні документи.

## Фотографії
У каталозі для всіх 18 позицій встановлено фотографії відповідних товарів із зовнішніх сайтів брендів/ритейлерів. Зображення завантажуються браузером за зовнішніми URL, тому для стабільного комерційного використання варто отримати дозвіл правовласників і зберегти ліцензовані файли у власній папці проєкту. Якщо сторонній сайт змінить адресу або заборонить hotlinking, окремі фото можуть не відображатися.
